Data flow through the Transformer

Same path as The Annotated Transformer / this repo’s notebook. German becomes numbers, then meaning, then English — one word at a time. Press play. You do not need to read code.

1. A sentence enters

The machine does not read letters like a person. First it splits the sentence into words (tokens), using spaCy — same as the notebook tokenize / load_tokenizers.

German Ein rotes Flugzeug fliegt
Words Ein rotes Flugzeug fliegt

2. Words become IDs + special tokens

build_vocabulary / load_vocab maps each word to a number. collate_batch wraps the sentence with start <s> and end </s>, then pads with <blank> so every example in a batch is the same length (max_padding, often 72).

IDs <s>+ 47812220190 +</s> <blank><blank>

A src mask later says: ignore the blanks. That is Batch.src_mask.

3. Each ID becomes a meaning vector (Embeddings)

Embeddings looks up a list of 512 numbers per word, then multiplies by √512 so position waves do not drown the meaning. German and English each have their own lookup table.

Ein → 512 numbers
rotes → 512 numbers
Flugzeug → 512 numbers

4. Position is added (PositionalEncoding)

Attention has no left-to-right order by itself. PositionalEncoding adds a unique sine/cosine pattern for slot 1, 2, 3… so “red plane” is not the same as “plane red”.

vector = meaning + position  →  still 512 numbers, still the same number of words

5. Encoder: words look at each other

Encoder stacks EncoderLayer N times (paper: 6). Each layer: LayerNorm + residual SubLayerConnection around (1) MultiHeadAttention self-attn and (2) PositionwiseFeedForward. clones copies layers so they do not share weights.

Self-attention: “red” looks hardest at “plane”.

Inside attention: scores = Q·K / √dk, hide pads with −1e9, softmax, mix V. Eight heads in parallel, then concat + output linear.

6. Eight heads, then a small MLP per word

Heads are 8 different “ways of looking.” Then every word goes through the same feed-forward net (512 → 2048 → 512, ReLU, dropout).

After N encoder layers + a final LayerNorm, you have memory — German meaning the decoder will read.

Memory Ein*rotes*Flugzeug*fliegt*

7. Decoder starts with only <s>

At translation time (greedy_decode / inference_test) English is not given. The decoder writes left to right. Training is different: Batch shows the gold English shifted by one (tgt vs tgt_y) — teacher forcing.

So far <s>

8. Causal mask — no peeking at the future

subsequent_mask builds a lower triangle. Batch.make_std_mask ANDs that with “not pad”. Decoder self-attention may only see words already written.

A red plane A ✓ · · red ✓ ✓ · plane✓ ✓ ✓

9. Three sub-layers in each DecoderLayer

Same residuals + dropout + norm as the paper’s decoder block.

1. Masked self-attention — among English so far
2. Cross-attention — queries from English, keys/values from memory (German), using src_mask
3. Feed-forward — same MLP as the encoder

Decoder repeats this N times, then a final norm. EncoderDecoder.decode runs target embeddings + PE first.

10. Generator picks the next word

Generator: linear to English vocab size, then log-softmax. Greedy decode takes only the last position, then argmax. Append that id to ys and loop until max length (or you stop at </s> in translate_german).

<s>→ A→ red→ plane→ </s>

Encode German once. Decode many times. Always batch size 1 in greedy decode so attention shapes stay correct.

11. How the model learns (training path)

create_dataloaders + Multi30k. run_epoch calls model.forward(src, tgt, masks), then SimpleLossCompute (generator + LabelSmoothing + KLDiv). Backprop, Adam, rate (Noam warmup). DummyOptimizer on eval. TrainState counts steps. train_model loops epochs and saves weights.

German batch & English batch → predict every next English word at once → compare to gold → nudge millions of numbers a tiny bit.
